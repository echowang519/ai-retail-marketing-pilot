# Demo Evidence Guide

Use this folder for public-safe visual evidence.

Good candidates:

- sanitized campaign preview
- Remotion composition preview
- campaign configuration UI mock or prototype
- before/after workflow diagram
- multi-format output comparison once validated

Do not publish:

- private retailer messages
- internal store documents
- customer or staff personal information
- unapproved brand or product assets

A visual should prove a specific part of the project rather than exist only as decoration.


## Prepared public evidence

Expected portfolio image:

- `prototype-evidence.png` — three-frame sanitized evidence strip showing the structured asset slot, data-driven price treatment and sanitized campaign ending.
