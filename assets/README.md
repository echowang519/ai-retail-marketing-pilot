# Public Asset Rules

This repository is a sanitized public case study.

Do not publish:

- retailer-owned internal materials
- private client conversations
- unapproved product packshots
- unapproved logos
- confidential pricing or campaign information
- personal data
- API keys or credentials

Public examples should use:

- placeholder products
- generic or self-created demo brands
- sanitized screenshots
- synthetic campaign data
- assets with clear publication rights

The goal is to demonstrate the workflow without exposing commercial or private material.
